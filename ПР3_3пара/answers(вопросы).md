# Ответы на вопросы для самоконтроля

## 1. В чем разница между селектором по классу и по ID с точки зрения специфичности и возможности повторного использования?

Селектор по классу обозначается точкой, например `.content`. Класс можно использовать у нескольких элементов страницы.

Селектор по ID обозначается символом `#`, например `#site-title`. ID должен быть уникальным для конкретного элемента страницы.

По специфичности ID имеет больший вес, чем класс. Поэтому класс удобнее использовать для повторного оформления элементов, а ID — для уникального элемента.

---

## 2. Как работает каскад в CSS и в каком порядке применяются стили при конфликте правил?

Каскад определяет, какое CSS-правило будет применено, если несколько правил задают разные значения одного свойства.

При конфликте учитываются происхождение и важность правила, специфичность селектора и порядок расположения правил в коде.

Если селекторы имеют одинаковую специфичность, применяется правило, которое находится ниже и было объявлено позже.

---

## 3. Рассчитайте специфичность для селекторов

### `ul li.important`

В селекторе присутствуют два селектора по тегу и один селектор по классу.

Специфичность:

**0, 0, 1, 2**

где:
- 0 — ID;
- 0 — классы, атрибуты и псевдоклассы;
- 1 — класс `important`;
- 2 — теги `ul` и `li`.

---

### `#site-title`

В селекторе присутствует один ID.

Специфичность:

**0, 1, 0, 0**

---

### `.content > .featured-post`

В селекторе присутствуют два класса.

Специфичность:

**0, 0, 2, 0**

Символ `>` сам по себе специфичности не добавляет.

---

## 4. Какие свойства в CSS наследуются по умолчанию, а какие нет? Приведите по 3 примера каждого типа.

По умолчанию наследуются некоторые свойства текста и шрифта.

Примеры наследуемых свойств:

1. `color`;
2. `font-family`;
3. `line-height`.

Примеры свойств, которые обычно не наследуются:

1. `margin`;
2. `padding`;
3. `border`.

Если необходимо явно передать значение родительского элемента, можно использовать значение `inherit`.

## 5. Как работает селектор `>` и чем он отличается от селектора потомков через пробел?

Селектор `>` выбирает только непосредственных дочерних элементов.

Например:

```css
.content > .featured-post
