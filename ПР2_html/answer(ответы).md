# Ответы на вопросы для самоконтроля

## 1. Чем семантическая верстка отличается от несемантической и почему она важна?

Семантическая верстка использует HTML-теги по их назначению: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`. Нелсемантическая верстка часто строится в основном на `<div>`. Семантическая разметка делает структуру страницы понятнее для пользователей, браузеров и поисковых систем.

## 2. В каких случаях следует использовать `<article>` вместо `<section>`? Приведите примеры из вашей работы.

`<article>` используется для самостоятельного содержимого, которое можно рассматривать отдельно от остальной страницы. `<section>` используется для тематического раздела страницы.

В моей работе `<section>` использован для разделов «Музыка и настроение» и «Музыкальные подборки», а `<article>` — для отдельных музыкальных подборок.

## 3. Для чего предназначены теги `<header>` и `<footer>` и могут ли они использоваться несколько раз на странице?

`<header>` предназначен для вводной части страницы или отдельного раздела, а `<footer>` — для заключительной информации. Они могут использоваться несколько раз, если относятся к разным разделам или элементам.

В работе `<header>` используется для шапки сайта и внутри отдельных статей, а `<footer>` — для основной информации внизу страницы.

## 4. Какой тег следует использовать для основного контента страницы и почему не стоит использовать для этого `<div>`?

Для основного содержимого следует использовать `<main>`. Он обозначает главную часть страницы и имеет семантическое значение. `<div>` является универсальным контейнером и сам по себе не показывает назначение содержимого.

## 5. В чем разница между `<nav>` и обычным списком ссылок? Когда обязательно использовать `<nav>`?

`<nav>` обозначает блок основной навигации страницы. Обычный список ссылок не обязательно является навигацией. `<nav>` следует использовать для важных групп навигационных ссылок, например меню сайта.

В моей работе `<nav>` содержит ссылки на основные разделы страницы.

## 6. Для чего используется атрибут datetime в теге `<time>` и почему он важен?

Атрибут `datetime` содержит дату или время в машиночитаемом формате. Он позволяет браузерам и другим программам правильно определить значение даты или времени.

Например:

```html
<time datetime="2026-09-16">16 сентября 2026 года</time>
